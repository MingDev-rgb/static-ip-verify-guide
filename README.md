# 你买到的究竟是什么：代理 IP 行业去魅指南

> **不推荐商家，只拆供应链。**
>
> 如果你搜过下面三句话，这篇就是写给你的：
>
> - 为什么每家都说是住宅？
> - 为什么检测站结果不一样？
> - 为什么 ASN 不对？
>
> 这不是一份“海外代理 IP 市场调研”，也不是“账号注册教程”。
> 它只回答一个问题：**你付钱之后，到底买到了供应链上的哪一层。**

**2026-11 修订**：这一版不再把“我测了 18 家”当主题。
18 家只是**显影剂**，用来证明一个更稳定的东西：**代理 IP 的供应链结构，决定了换商家结果也会趋同。**

## 一、结论

1. **你买的不是“住宅 IP”，是一张转售凭证。** 商家卖的是“概率”，不是“线路”。
2. **真住宅不在卡池里。** 它绑在具体地址、具体 CPE、具体人名下；能 1:1 卖，不能切成随机凭证批发。
3. **全行业都是抽卡。** 下游、中游、上游，底层都是“池子里随机分配”；差别只是抽中干净段的概率。
4. **上游不是“真货层”，只是“赔率更高的卡池”。** 没有一家把“指定 ASN + `Server = No`”写进标准交付承诺。
5. **市场没有真正的分层定价。** 同一个池子可以换五个门面、卖五种价格；定价看品牌和话术，不看资源等级。
6. **身份是门票，记录是座位。** ASN/注册人/线路位置决定“能不能进场”；Fraud/黑名单/`Server` 决定“进场后坐哪”。
7. **推荐商家没有意义。** 因为推荐的本质，变成了“推荐一个卡池”。

> **核心判断：这篇文章的价值，不是告诉你哪家是骗子，而是告诉你——你离运营商还有几层。**

## 二、七层资源等级

| 等级 | 定义 | 典型 | 卡池里能买到吗 |
|---|---|---|---|
| **1. 真住宅** | 运营商消费级线路，绑地址/CPE/人名；可 1:1 卖，不能批发 | 自己家宽、海外朋友家宽、手机漫游 | **几乎不流通** |
| **2. 小众段 ISP 零售** | 小 ISP 直营/零售静态段，direct allocation 或 ISP 分配 | I-2000 | **极少**，靠本地关系/运气 |
| **3. 大众段 ISP 零售** | NTT/Comcast/HiNet 等零售商宽/专线静态 IP | 本地商宽、专线 | **不对境外散户零售** |
| **4. ISP 代理** | 供应商租 ISP 段，机房/POP 托管；ASN 可能真是 ISP | Astound/CenturyLink 代理 | 有，但抽卡 |
| **5. 机房伪装 ISP** | 拿 ISP/小运营商名字包装，实际 hosting/代理网络 | Lumina/Lietparkas、部分 Arisk | 大量 |
| **6. IDC 机房 IP** | 明确 hosting/IDC ASN | Arisk/DIL/Bunny | 大量 |
| **7. 广播数据中心** | Tier-1 广播下的客户段，ASN 像 ISP，实际数据中心 | Westeros/NTT、Wisdom/IIJ | 大量 |

**记住顺序：**

> 真住宅 > 小众 ISP 零售 > 大众 ISP 零售 > ISP 代理 > 机房伪装 ISP > IDC > 广播数据中心

展开的定义、案例、为什么没有“定制真住宅”，见 [文档 11](docs/11-你买到的究竟是什么.md)。

## 三、价值论：离真实用户越近，价值越高

| 路径 | 离真实用户 | 价值 | 能不能规模化卖 |
|---|---|---|---|
| **运营商专线 / 本地商宽** | 最近 | 最高 | 要当地身份/地址/安装，不能零售给境外散户 |
| **海外朋友家宽（经同意）** | 很近 | 很高 | 1:1，人情，不能批发 |
| **国际漫游数据** | 近 | 高 | 应急，会变/共享 |
| **ISP 零售** | 中 | 中高 | 要合同/安装，起订量高 |
| **ISP 代理** | 远 | 中 | 能卖，但服务器在机房 |
| **机房伪装 ISP** | 更远 | 低 | 大量 |
| **IDC / 广播数据中心** | 最远 | 最低 | 大量 |

> **经过的中间商越多，价值越低。**
> 代理 IP 不是“商品”，是“转售凭证”；你买的不是那个 IP，是它离运营商的距离。

## 四、为什么没有“定制真住宅”商家

因为从商业上不成立：

- 运营商自己就能开线、分配静态 IP，**不需要中间商**；
- 真住宅要绑地址、CPE、人名，**不能切成随机凭证批发**；
- 运营商不会为一个小海外买家拆段；
- 所以“定制真住宅”要么是本地线路转售，要么是机房伪装；
- **能规模化卖的“住宅”，一定已经进入代理链条，不再是真住宅。**

这不是“商家不够良心”，是**供应链结构不允许**。

---

## 五、为什么市场没有明确的分层定价

| 原因 | 结果 |
|---|---|
| 买家无法验证 ASN/注册人/线路位置 | 卖家可以用“原生/双 ISP/住宅”统一包装 |
| 同一个池子可以换多个门面 | 同货不同价，价格看品牌不看等级 |
| 抽卡隐藏了方差 | 你买到的是概率，不是确定等级 |
| 退款/换货成本高 | 卖家没有动力披露真实层级 |
| 推荐带返佣 | “测评”本身有立场 |

所以：**把某一家说成“稳”，说到底是在推荐一个卡池。**
换商家，不如换等级；换等级，不如换路径。

## 六、抽卡论：为什么换商家没用

- 下游、中游、上游，底层都是“池子里随机分配”；
- 上游只是**抽卡次数更多、单价更低**，不是“真货层”；
- 同一批经纪人段，可以同时供给多家下游；
- 日本便宜池就是例子：`103.*.148` / `43.*.197` 是 Arisk，`103.*.120` 是 NTT/M-Square，整段黑名单；
- **不是日本 ISP 全黑，是这条便宜供应链全黑。**

18 家样本、抽卡概率表、日本池三件套、脱敏池反查，见 [文档 09](docs/09-实测数据集.md)。

## 七、判断标准：身份优先，记录其次

拿到一个 IP，按这个顺序看：

1. **RDAP**：号段注册在谁名下？是 ISP、hosting，还是经纪人？
2. **RIPEstat**：当前由哪个 ASN 广播？广播方 ≠ 持有者。
3. **Scamalytics**：`Server` / `Anonymizing VPN` / Fraud。
4. **黑名单**：Spamhaus SBL / AbuseIPDB；整段黑名单，换尾数没用。
5. **ping0 / 其他站**：只作交叉参考，别当唯一判据。

**身份是门票，记录是座位。**

- 身份干净 + 记录脏 → 还有救（换 IP/等解封）；
- 身份脏 + 记录干净 → 对查 ASN/类型的平台，仍然出局；
- 分数干净 ≠ 身份干净；
- 一家说“Residential”，另一家说“IDC”，先看 RDAP，不要先信标签。

完整命令见 [文档 01](docs/01-如何验证一个IP的真实身份.md)；
检测站为什么打架见 [文档 02](docs/02-检测站口径的真相.md)。

## 八、养号结论：IP 只是其中一层

| 需求 | 最低档 | 说明 |
|---|---|---|
| **注册 / 养号 / 长期运营** | **ISP 零售** | 够用；但还要账号、手机号、浏览器、支付、行为一致 |
| **勉强能用** | **ISP 代理** | 有风险，抽卡，不保证 |
| **机房伪装 / IDC / 广播** | **不建议** | 掩耳盗铃，不如继续用梯子 |
| **只要看内容 / 搜索** | 干净梯子即可 | 不必买“住宅”标签 |

**账号层不是这篇的重点。**
手机号、浏览器指纹、支付方式、登录行为，都会影响风控；
但那些是另一个问题，本文不展开，也不提供绕过实名的做法。

> **IP 不能单独把账号“养白”；它只能不拖后腿。**

## 九、替代路线：要线路，不要标签

| 路线 | 适合 | 代价 |
|---|---|---|
| **当地运营商商宽/专线** | 长期、稳定、真线路 | 当地身份/地址/安装/月费 |
| **海外朋友家宽（经同意）** | 1:1、应急、长期 | 人情、维护、不能批发 |
| **手机卡国际漫游** | 一次性注册/应急 | 漫游费、IP 会变/共享 |
| **ISP 零售** | 只要“干净” | 起订量/合同/本地关系 |
| **干净梯子** | 只看内容/搜索 | 不解决账号身份 |

**买“静态住宅代理”不在“真住宅”的替代路线里。**
它最多是“ISP 代理”，不是“线路”。

## 十、常见问题

**Q：「原生 IP」是住宅 IP 吗？**
A：**不是**。它只表示“注册国 = 位置国”；本地机房段也可以是“原生”。

**Q：为什么同一个 IP，ping0 说“家庭宽带”，别的网站说“数据中心”？**
A：它们量的不是同一个东西。ping0 的“家庭宽带”是兜底标签；别的站可能看 ASN/公司类型。
详见 [文档 02](docs/02-检测站口径的真相.md)。

**Q：为什么我换了三四家，感觉买到的还是同一批货？**
A：因为中文零售商的货，大多来自同一批 IP 经纪人/上游段。
换门面不换货架；用 RDAP 查注册名就明白了。详见 [文档 03](docs/03-经纪人号段的识别.md)。

**Q：上游是不是也全是假货？**
A：按“用户侧真住宅线路”的定义，是；按“ISP 注册段”的定义，它们有真段，但服务器在机房。
上游只是把抽中率提高一点，没有把抽卡变成点菜。详见 [文档 09](docs/09-实测数据集.md)。

**Q：那真 ISP 到底怎么搞？**
A：三条路：**当地运营商商宽/专线**、**海外朋友家宽（经同意）**、**手机卡国际漫游**。
买“静态住宅代理”不在其中。详见 [文档 09](docs/09-实测数据集.md)。

**Q：我只是要“干净”，不执着于“真住宅”，买什么？**
A：**稀有小型 ISP 段**：RDAP registrant 是 ISP、`Server = No`、Fraud 低、不在黑名单。
只买短周期、先验示例 IP、续费前复验；库存极小。详见 [文档 09](docs/09-实测数据集.md)。

**Q：为什么说“全是假货”？**
A：这里的“假”是**品类判断**：按“住宅 ISP”卖，实际给的是机房/经纪人段；不是法律意义上的假冒伪劣。

**Q：需要自建 VPS 吗？**
A：看你想解决什么问题：
- ❌ 想靠 VPS 解决“IP 身份” → 不行（VPS 是纯机房 IP）；
- ✅ 想替代机场当“中转” → 可以；
- ✅ 不想折腾 → 直接用现成机场当前置。
详见 [文档 10](docs/10-自建链路（链式代理与VPS+ISP）.md)。

**Q：推荐哪家？**
A：**不推荐。** 推荐的本质是推荐一个卡池；这篇只给等级、判据和路径。

## 十一、这份文档是怎么做的

所有结论来自**实测、公开数据与结构分析**，不是转述：

| 方法 | 说明 |
|---|---|
| **RDAP / WHOIS** | 向 RIR（ARIN / RIPE / APNIC）查询号段注册持有者 |
| **RIPEstat** | 查号段当前由哪个 ASN 广播（与持有者常不同） |
| **Scamalytics** | 查 `Server` / `Residential Proxy` / `Datacenter` / 黑名单字段 |
| **ping0 / ipinfo / 其他站** | 交叉参考，不作为唯一判据 |
| **商家官方页面 + 客服原话** | 价格、起订量、退款条款、支付方式，全部留证 |
| **实际购买并实测** | 买最小额，拿到 IP 立刻验证 |
| **上游补测** | 表内 4 家上游（+1 大厂对照）：第三方 115 IP 购买实测 + 读者复现 + 页面/条款核对 |

**数据采集时间**：下游 **2026 年 9 月**；上游补测 **2026 年 10 月**；补充样本 **2026 年 11 月**。
价格与政策会变，请以官方当前页面为准。

**证据分级**：自购实测 / 第三方或读者购买实测 / 页面条款核对 / 结构性论证，逐条标在 [文档 09 · 附录 C](docs/09-实测数据集.md)。
