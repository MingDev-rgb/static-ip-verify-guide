## 二、核心结论（三句话）

1. **"原生 IP" ≠ 住宅 IP**。它只表示"注册国 = 位置国"，**本地机房段也可以是"原生"**。
2. **各检测网站的标签不可跨站比较**。同一个 IP 在不同库里结论可以完全相反 —— **它们量的是不同东西**。
3. **只有 RIR 注册数据（RDAP）是"事实层"**。问一个 IP 的"真身"，**看它的号段注册在谁名下**。

## 四、常见问题（FAQ）

**Q：「原生 IP」是住宅 IP 吗？**
A：**不是**。在行业用法里"原生"通常只表示**注册国家与 IP 实际位置国家一致**。
本地机房段、本地 IDC 段都可能是"原生"。判断是不是住宅，要看**号段的注册持有者是不是运营商**（见文档 01）。

**Q：怎么判断一个 IP 是"机房段"还是"住宅段"？**
A：查三样东西：
① **RDAP** 看 `netname`（号段注册在谁名下 —— 运营商 or 主机商）；
② **RIPEstat** 看广播 ASN（是不是挂在 NTT/GTT/Cogent 这类 Tier-1 骨干下）；
③ **Scamalytics** 看 `Proxies → Server` 字段（`Yes` = 商用服务器）。
完整方法见 [文档 01](docs/01-如何验证一个IP的真实身份.md)。

**Q：为什么同一个 IP，ping0 说"家庭宽带"，别的网站说"数据中心"？**
A：因为**它们量的不是同一个东西**：ping0 用人工标注的段名单（且"家庭宽带"是**兜底标签**："除机房名单以外的一律标家宽"）；
ip.cx 看的是**广播方**（Tier-1 骨干一律判数据中心）；Scamalytics 看的是**服务器特征与欺诈记录**。
详见 [文档 02](docs/02-检测站口径的真相.md)。

**Q：「双 ISP」「双 NTT」是什么意思？**
A：大概率是**号段被转手过的历史痕迹** —— 同一个段在数据库里留下过多家运营商的名字。
**它不是"双线家宽保障"，更不是质量指标。** 详见 [文档 03](docs/03-经纪人号段的识别.md)。

**Q：为什么我换了三四家商家，感觉买到的还是同一批货？**
A：因为中文零售商的货**大多来自同一批 IP 经纪人（号段持有者）**。
换门面不换货架 —— 用 `RDAP` 查一下注册名就明白了。详见 [文档 03](docs/03-经纪人号段的识别.md)。

**Q：1 个"真运营商段"的 IP，最低多少钱？**
A：实测（2026-09）：**运营商段的零售起订量是 10~25 个起**，折合 **$14 ~ $45**。
**"1 个 + 真 ASN + 低价"这个组合在市场上结构性不存在。** 详见 [文档 04](docs/04-静态IP市场的分层与价格带.md)。

**Q：只有支付宝、不想实名，能买吗？**
A：能，但要接受取舍：**支持支付宝的（多为中文零售商）大概率给的是机房/小 ISP 段**；
**敢写 ASN 的上游**通常只收信用卡/PayPal/加密货币。详见 [文档 04](docs/04-静态IP市场的分层与价格带.md)。

**Q：注册 ChatGPT 可以用 Google Voice / 接码平台吗？**
A：**Google Voice 不行** —— OpenAI 帮助中心明确写明**不接受 VoIP、固话和 premium number**。
**接码平台的号**因被大量滥用，**大面积被拒**，且**号不是你的**（将来无法重新验证）。详见 [文档 05](docs/05-OpenAI的手机号政策.md)。

**Q：那用什么号最稳？**
A：**真实移动运营商号**（实体 SIM 或运营商 eSIM）。
拿到号后可先用 `phonevalidator.com` 之类的服务查 `Line Type`，显示 **`CELL PHONE`** 才有戏。详见 [文档 06](docs/06-手机号方案对比.md)。

**Q：+86 手机号能注册美区 Apple ID 吗？**
A：**能**。Apple ID 的注册**不需要海外手机号**（+86 即可），
需要的是"**美国 IP + 无痕浏览**"才会出现付款方式选「**无**」的选项。详见 [文档 07](docs/07-从零到能用GPT的完整流程.md)。

**Q：国内信用卡能订阅 ChatGPT Plus 吗？**
A：**网页版直接绑国内卡基本失败**（发卡行识别 + 3DS 验证）。
可行路径是 **iOS 内购**：支付宝买 Apple 礼品卡 → 兑换到美区 ID → iPhone 上 App 内购。详见 [文档 07](docs/07-从零到能用GPT的完整流程.md)。

**Q：怎么跟客服问，才能不买到假货？**
A：直接用 [文档 08](docs/08-常见套路与沟通话术.md) 里的**问询模板**（中英双语），
核心就三个问题：**具体 ASN 是多少 / 支持什么支付 / 能否给同产品线的测试 IP**。

## 五、这份调研是怎么做的

所有结论来自**实测与官方原文**，不是转述：

| 方法 | 说明 |
|---|---|
| **RDAP / WHOIS** | 向 RIR（ARIN / RIPE / APNIC）查询号段**注册持有者** |
| **RIPEstat** | 查号段**当前由哪个 ASN 广播**（与持有者常不同） |
| **Scamalytics** | 查 `Server` / `Residential Proxy` / `Datacenter` / 黑名单字段 |
| **ipinfo** | 查 org / 国家（注意：经常返回空） |
| **商家官方页面 + 客服原话** | 价格、起订量、退款条款、支付方式，全部留证 |
| **实际购买并实测** | 买最小额，拿到 IP 立刻按上述方法验证 |

**数据采集时间：2026 年 9 月**（价格与政策会变，请以官方当前页面为准）
