## 二、核心结论（六句话）

1. **“原生 IP” ≠ 住宅 IP**。它只表示“注册国 = 位置国”，**本地机房段也可以是“原生”**。
2. **各检测网站的标签不可跨站比较**。同一个 IP 在不同库里结论可以完全相反 —— **它们量的是不同东西**。
3. **只有 RIR 注册数据（RDAP）是“事实层”**。问一个 IP 的“真身”，**看它的号段注册在谁名下**。
4. ⭐ **下游零售 = 抽卡 —— 而且这盒卡里没有好牌。** 多家中国零售商的“德国原生 ISP”实测来自
   **同一个号段持有者**（NovProxy / LinkStatic / LokiProxy 的德国货全部落在一家 IP 经纪人名下）。
   **我们换过商家、换过国家档、隔时间再取样 —— 拿到的始终是同一批骨干/机房段。**
   **不是“运气不够”，是货架上本来就没有真货**（它们的进货渠道高度集中）。
   机制、证据、池子地图 → [文档 09 · 附录 A](docs/09-实测数据集.md)
5. ⭐ **上游 = 赔率更高的抽卡，不是“真货层”。** 表内 4 家上游（+1 家大厂对照）里，
   Bart 的 115 个 IP 购买实测：**3/7 包是住宅/移动、1/7 是机房，ASN 与 ISP 名匹配 28.57%**；
   其余没有一家承诺“指定 ASN + `Server = No`”；还有读者按报告去买，遇到的仍是同样的抽卡。
   **换到上游，只是换一张赔率更高的赌桌。**
   → [文档 09 · 零·四](docs/09-实测数据集.md)
6. ⭐ **真住宅不在卡池里。** 它在别人家的路由器/线路上，绑在具体地址、具体 CPE、具体人名下；能 1:1 卖，不能切成随机凭证批发。
   **要真住宅：当地商宽/专线 > 海外朋友家宽 > 手机卡漫游；只要干净：稀有小型 ISP 段。**
   → [文档 09 · 零·五 / 零·七 / 零·八](docs/09-实测数据集.md)

## 二·六、有些东西不是不想写，是不能写

这份文档看起来已经很“掀桌子”了，但它仍然删掉了比正文更硬的内容。

| 我们删掉的内容 | 为什么不能写 |
|---|---|
| **具体上游/经纪人的对接人、合同价、返点** | 个人信息 + 商业机密；写了会连累提供信息的人 |
| **绕过 KYC / 实名 / 支付风控的具体步骤** | 等于教人规避监管；不写，也不建议任何人做 |
| **控制/入侵他人路由器、把住宅设备变成节点的做法** | 侵权/违法；这条线不碰 |
| **未脱敏的样本 IP、订单、账号** | 会牵连真实买家/用户 |
| **某些平台的风控阈值、内部口径** | 涉及平台安全/NDA；不写 |

**这不是卖关子。**

- 能写的，我们都给了**可复现的命令**（RDAP / RIPEstat / Scamalytics）；
- 不能写的，我们不拿它当“内部消息”卖点，也不暗示“加钱就能买到”；
- **我们知道的比写出来的多** —— 但“知道”不等于“可以公开”。

> 所以这份文档只给**判据**，不给“能买到真货的名单”——因为后者不存在。
> 谁要是在评论区卖你“真住宅名单”，他就是这份文档要拆的那种人。

## 四、常见问题（FAQ）

**Q：「原生 IP」是住宅 IP 吗？**
A：**不是**。在行业用法里"原生"通常只表示**注册国家与 IP 实际位置国家一致**。
本地机房段、本地 IDC 段都可能是"原生"。判断是不是住宅，要看**号段的注册持有者是不是运营商**（见文档 01）。

**Q：怎么判断一个 IP 是"机房段"还是"住宅段"？**
A：查三样东西：
① **RDAP** 看 `netname`（号段注册在谁名下 —— 运营商 or 主机商）；
② **RIPEstat** 看广播 ASN（是不是挂在 NTT/GTT/Cogent 这类 Tier-1 骨干下）；
③ **Scamalytics** 看 `Proxies → Server` 字段（`Yes` = 商用服务器）。
完整方法见 [文档 01](docs/01-如何验证一个IP的真实身份.md)。

**Q：为什么同一个 IP，ping0 说"家庭宽带"，别的网站说"数据中心"？**
A：因为**它们量的不是同一个东西**：ping0 用人工标注的段名单（且"家庭宽带"是**兜底标签**："除机房名单以外的一律标家宽"）；
ip.cx 看的是**广播方**（Tier-1 骨干一律判数据中心）；Scamalytics 看的是**服务器特征与欺诈记录**。
详见 [文档 02](docs/02-检测站口径的真相.md)。

**Q：「双 ISP」「双 NTT」是什么意思？**
A：大概率是**号段被转手过的历史痕迹** —— 同一个段在数据库里留下过多家运营商的名字。
**它不是"双线家宽保障"，更不是质量指标。** 详见 [文档 03](docs/03-经纪人号段的识别.md)。

**Q：为什么我换了三四家商家，感觉买到的还是同一批货？**
A：因为中文零售商的货**大多来自同一批 IP 经纪人（号段持有者）**。
换门面不换货架 —— 用 `RDAP` 查一下注册名就明白了。详见 [文档 03](docs/03-经纪人号段的识别.md)。

**Q：1 个"真运营商段"的 IP，最低多少钱？**
A：实测（2026-09）：**运营商段的零售起订量是 10~25 个起**，折合 **$14 ~ $45**。
**"1 个 + 真 ASN + 低价"这个组合在市场上结构性不存在；上游补测后还要加一句：10~25 个起，也不保证"指定 ASN + Server=No"。** 详见 [文档 04](docs/04-静态IP市场的分层与价格带.md)。

**Q：只有支付宝、不想实名，能买吗？**
A：能，但要接受取舍：**支持支付宝的（多为中文零售商）大概率给的是机房/小 ISP 段**；
**敢写 ASN 的上游**通常只收信用卡/PayPal/加密货币。详见 [文档 04](docs/04-静态IP市场的分层与价格带.md)。

**Q：注册 ChatGPT 可以用 Google Voice / 接码平台吗？**
A：**Google Voice 不行** —— OpenAI 帮助中心明确写明**不接受 VoIP、固话和 premium number**。
**接码平台的号**因被大量滥用，**大面积被拒**，且**号不是你的**（将来无法重新验证）。详见 [文档 05](docs/05-OpenAI的手机号政策.md)。

**Q：那用什么号最稳？**
A：**真实移动运营商号**（实体 SIM 或运营商 eSIM）。
拿到号后可先用 `phonevalidator.com` 之类的服务查 `Line Type`，显示 **`CELL PHONE`** 才有戏。详见 [文档 06](docs/06-手机号方案对比.md)。

**Q：+86 手机号能注册美区 Apple ID 吗？**
A：**能**。Apple ID 的注册**不需要海外手机号**（+86 即可），
需要的是"**美国 IP + 无痕浏览**"才会出现付款方式选「**无**」的选项。详见 [文档 07](docs/07-从零到能用GPT的完整流程.md)。

**Q：国内信用卡能订阅 ChatGPT Plus 吗？**
A：**网页版直接绑国内卡基本失败**（发卡行识别 + 3DS 验证）。
可行路径是 **iOS 内购**：支付宝买 Apple 礼品卡 → 兑换到美区 ID → iPhone 上 App 内购。详见 [文档 07](docs/07-从零到能用GPT的完整流程.md)。

**Q：怎么跟客服问，才能不买到假货？**
A：直接用 [文档 08](docs/08-常见套路与沟通话术.md) 里的**问询模板**（中英双语），
核心就三个问题：**具体 ASN 是多少 / 支持什么支付 / 能否给同产品线的测试 IP**。

**Q：上游是不是也全是假货？**
A：按“用户侧真住宅线路”的定义，是；按“ISP 注册段”的定义，它们有真段，但服务器在机房，风控通常仍判 `Server = Yes`。
上游只是把“抽中率”从“几乎为 0”提高到“好一点”，没有把抽卡变成点菜；有读者按这份报告去买，反馈也是同样的抽卡。详见 [文档 09 · 零·四](docs/09-实测数据集.md)。

**Q：那真 ISP 到底怎么搞？**
A：三条路：**当地运营商商宽/专线**（要当地身份/地址，贵）、**海外朋友家宽**（经同意，1:1，人情）、**手机卡国际漫游**（应急，会变/共享）。
买“静态住宅代理”不在其中。详见 [文档 09 · 零·七](docs/09-实测数据集.md)。

**Q：我只是要“干净”，不执着于“真住宅”，买什么？**
A：**稀有小型 ISP 段**：RDAP registrant 是 ISP、`Server = No`、Fraud 低、不在黑名单。
只买短周期、先验示例 IP、续费前复验；库存极小，说没就没。详见 [文档 09 · 零·八](docs/09-实测数据集.md)。

**Q：为什么说“全是假货”？**
A：这里的“假”是**品类判断**：按“住宅 ISP”卖，实际给的是机房/经纪人段；不是法律意义上的假冒伪劣。
每条判断都有 RDAP / Scamalytics 可复现；详见 [文档 09 · 零·二](docs/09-实测数据集.md)。

---

**Q：需要自建 VPS 吗？**
A：**看你想解决什么问题** ——
- ❌ **想靠 VPS 解决"IP 身份"→ 不行**（VPS 是纯机房 IP，风控库直接判 `Server = Yes`）
- ✅ **想替代机场当"中转"→ 可以**（路径自主、不经第三方）
- ✅ **不想折腾 → 直接用现成的机场当前置**（多数人的选择）

两条路线的完整对比见 [文档 10](docs/10-自建链路（链式代理与VPS+ISP）.md)。

**Q：自己搭链路，用什么软件？**
A：**本仓库不推荐具体项目** —— 这类软件更新太快，推荐很快过时。
去 GitHub 按 **star 数 + 最近更新时间**自己挑，关键词：`clash` / `mihomo` / `sing-box` / `v2rayN`；
**挑的时候务必确认它支持"指定上游代理"**（各软件叫法不同：`dialer-proxy` / `detour` / `upstream proxy`），
否则做不了"前置 + 落地"的链式结构。详见 [文档 10 第六节](docs/10-自建链路（链式代理与VPS+ISP）.md)。

## 五、这份调研是怎么做的

所有结论来自**实测与官方原文**，不是转述：

| 方法 | 说明 |
|---|---|
| **RDAP / WHOIS** | 向 RIR（ARIN / RIPE / APNIC）查询号段**注册持有者** |
| **RIPEstat** | 查号段**当前由哪个 ASN 广播**（与持有者常不同） |
| **Scamalytics** | 查 `Server` / `Residential Proxy` / `Datacenter` / 黑名单字段 |
| **ipinfo** | 查 org / 国家（注意：经常返回空） |
| **商家官方页面 + 客服原话** | 价格、起订量、退款条款、支付方式，全部留证 |
| **实际购买并实测** | 买最小额，拿到 IP 立刻按上述方法验证 |
| **上游补测** | 表内 4 家上游（+1 大厂对照）：第三方 115 IP 购买实测 + 读者复现 + 官网/下单器/条款核对；另有未写进报告的样本 |

**数据采集时间**：下游 **2026 年 9 月**；上游补测 **2026 年 10 月**（价格与政策会变，请以官方当前页面为准）。

**证据分级**：自购实测 / 第三方或读者购买实测 / 页面条款核对 / 结构性论证，逐条标在 [文档 09 · 附录 C](docs/09-实测数据集.md)。
