## 三、从这张表能读出的三个事实

### 事实 1：**"1 个 + 真运营商 ASN + ≤$5"这个组合不存在**

- 写 ASN 的（上游）：**10~25 个起**，$14~$75
- 1 个起卖的（下游）：**不写 ASN**，且实测样本多为机房段
- **两者没有交集**（我们实测 18 家）

### 事实 2：**多家下游的德国货来自同一批号段**

| 商家 | 宣称 | 实测 |
|---|---|---|
| NovProxy | 德国原生住宅 | AS395793 **Arisk Communications inc.** |
| LokiProxy | 德国原生 ISP（"双 NTT"） | `145.79.75.*` → 广播 **AS2914 NTT** |
| LinkStatic | 德国原生 ISP | `145.79.126.0/24` → RDAP netname = **Arisk**，广播 AS2914 NTT |

→ **三家指向同一个号段持有者**（复现方法见文档 01、案例见文档 03）

### 事实 3：**"原生""双ISP""双NTT"这类词，与"是不是住宅"无关**

- "原生" = 注册国与位置国一致（本地机房段也是"原生"）
- "双 ISP" = 该段历史上挂过多个运营商名字（倒手痕迹）
- "双 NTT" = 由 Tier-1 骨干广播 —— **骨干网络正是最像机房的一类**

## 四、如何自己复现这张表里的每一个 ASN 结果

```bash
# ① 号段持有者（RIR 官方注册数据）
curl -s "https://rdap.db.ripe.net/ip/<IP>" | jq '{handle, name, country, type}'

# ② 当前广播方（BGP）
curl -s "https://stat.ripe.net/data/prefix-overview/data.json?resource=<IP>" \
  | jq '.data | {resource, asns: [.asns[] | {asn, holder}]}'

# ③ 第三方风控判定（需浏览器，有反爬）
# https://scamalytics.com/ip/<IP>   → 看 Proxies → Server 字段
```

**如果某个商家的示例 IP 用上面三步查出来的 `netname` 是主机商、且 `Server = Yes`，那它就是机房段。** —— 这不是我们的判断，是 RIR 注册记录与风控库字段的显示结果。
