# 08 · 常见套路与沟通话术（含可直接复制的客服问询与退款模板）

**把这一路遇到的话术拆开，附可复制的客服问询模板。**

---

## 一、话术拆解表

| 商家说 | 实际含义 | 怎么验 |
|---|---|---|
| **"原生 IP"** | 仅指"注册国 = 位置国"（**和是不是住宅无关**，本地机房段也可以是"原生"） | 看 RDAP 的 `netname` |
| **"双 ISP / 多 ISP"** | 该号段**历史上挂过多个运营商的名字**（倒手痕迹） | 看 ping0 的"ASN 历史" |
| **"双 NTT 线路"** | 该段由 **Tier-1 骨干**广播 —— **骨干网络正是最像机房的一类** | RIPEstat 查广播 ASN |
| **"优质的 ASN 供应商"** | **没写具体 ASN** = 给不出承诺 | 直接问 ASN，看它怎么答 |
| **"100% 独享 / 不与他人共享"** | 商家承诺，但**没有任何第三方能验证** | 看它敢不敢给测试 IP |
| **"机房 IP 也能用"（商家辩解）** | 事实层面没错，但**用户要的是住宅身份** | 立场不同，无法靠争论解决 |
| **"检测以 XX 为准"** | 单方援引对**它自己有利**的那个数据库 | 让它指出**哪条条款**这么规定的 |

---

## 二、四种常见套路

### 套路 1：测试额度给的是"别的产品线"

| 你问 | 它给 | 问题 |
|---|---|---|
| "能不能测你们的静态住宅？" | 给你**动态住宅流量** / **短效 IP** / **别的国家**的试用 | **测的不是你要买的东西** |

**对策**：明确要求 **"和我要买的产品同一个产品线"** 的测试 IP，最好是**同国家、同段**。

---

### 套路 2：给示例 IP（好现象）vs 只给口头承诺

| 情况 | 解读 |
|---|---|
| 商家在页面上**展示示例 IP** | ✅ 你可以立刻验证 → **这类商家相对坦荡** |
| 商家只给"客服口中的测试 IP" | ⚠️ 测试 IP 常来自**空闲池**，**未必代表正式库存** |
| 商家**拒绝任何测试** | ⚠️ 真货不怕验 |

---

### 套路 3：口头承诺 vs 条款

- 客服说"**可以换**" / "**可以退**" → 这是**口头**
- **以它官网的条款为准**（条款里通常写得比客服保守）

**对策**：
1. **把客服承诺截图**（作为"描述不符"的依据）；
2. **让它把承诺写进工单/聊天记录**；
3. 争议时**优先引用条款编号 + 官方原文**（比吵闹有效）。

---

### 套路 4：退款的隐形门槛

实测见过的几种退款政策：

| 政策原文大意 | 实际含义 |
|---|---|
| "服务无形且不可撤销，**下单后不退款**" | ❌ 不可退 |
| "**只有永久关闭账户**时才能退余额" | ⚠️ 等于钱进得去出不来（除非你不用了） |
| "**非 IP 质量问题不予退款**" | ✅ **反过来：IP 质量问题可退** ← **这是可以用的抓手** |
| "subscription renews automatically until cancelled" | ⚠️ 记得取消自动续费 |
| "24 小时内出现重大缺陷可全额退" | ✅ 有退款窗口（**要在窗口内提**） |

**行业常态**：**不可退款是这行的主流**。所以：

> **可退的** → 买最小额，拿到立刻验；
> **不可退的** → **下单前先拿到 ASN 承诺或测试 IP**，否则只能当赌注。

## 三、可复制的客服问询模板

### 模板 A：买静态 IP 前（中文）

```
你好，我要买【国家】静态 ISP（1 个 IP / 30 天，独享固定），用途是做固定的网络出口。
下单前请只回答这 3 个问题：

1）这个 IP 会落在哪个 ASN / 哪个运营商名下？请给【具体 ASN 号】
   （例如 Deutsche Telekom AS3320、Vodafone AS3209）。
   如果贵司不掌握，请直接回答"无法提供 ASN"——没关系，我只需要知道真相。

2）支持支付宝/微信吗？需要实名或上传证件吗？

3）能否先给我一个【与正式购买同一产品线】的测试 IP（不是动态住宅、不是短效、
   不是别的国家）？哪怕只有 1 小时。
```

**判定标准**：

| 回答 | 结论 |
|---|---|
| 给了具体 ASN + 支付可用 + 不要证件 | ✅ 可以买最小额试 |
| "随机" / "优质 ISP 供应商" / "无法提供" | ❌ 跳过 |
| 要身份证/人脸 | ❌ 跳过 |
| 只有卡/加密货币 | ❌ 支付不通 |

---

### 模板 B：英文版（发给海外商家）

```
Hi, before purchasing I need to confirm 3 things about your Static ISP product
(1 IP / 30 days, dedicated, for a fixed egress):

1) Which ASN will the assigned IP be on? Please state the specific ASN number
   (e.g. Deutsche Telekom AS3320, Vodafone AS3209).
   If you cannot guarantee a specific ASN, please say so directly — that's fine,
   I just need to know.

2) Do you accept Alipay? Is KYC / ID verification required?

3) Can you provide a test IP from the SAME product line as the purchase
   (not rotating residential, not short-lived, not a different country)?
```

---

### 模板 C：拿到 IP 后的验货（自己跑，不求人）

```
① RDAP：    查 netname（真实持有者）
② RIPEstat：查广播 ASN
③ Scamalytics：看 Organization Name + Proxies → Server
④ ping0：   看风控值（别看"家庭宽带"标签）
```

**判定**：
- `Server = Yes` 或 netname 是主机商 → ❌
- `Server = No` + netname 是小 ISP/运营商 → ✅ 可以用

---

### 模板 D：退款/换货话术（IP 质量问题）

```
你好，我购买的【国家】静态 ISP（订单号 XXX / 提取时间 XXX），实测结果如下：

1. RDAP 查询（RIR 官方注册数据）：该号段的注册持有者为【X 公司】，
   属于主机商/网络技术公司，并非产品页承诺的"本地 ISP 原生段"；
2. Scamalytics 查询：该 IP 的 Proxies→Server 字段为 Yes（判定为商用服务器），
   页面结论写明 "not a standard domestic connection, it is a commercial server"；
3. 贵站产品页对"原生"的描述为【引用原文】。

以上属于「IP 质量与宣传不符」，请按贵站退款政策中关于【IP 质量不达标】的条款处理：
① 更换一个 ASN 属于当地运营商的【国家】静态 IP；或
② 将本单金额退回我的账户余额。

相关截图可提供。
```

**要点**：
1. **只引用**：RIR 注册数据 + 第三方字段 + 商家自己的页面原文（**都是可验证的**）；
2. **引用条款编号**（不是情绪）；
3. **给出两个可选方案**（换/退），比"我要退款"更容易被接受。

---

## 四、三条底线

| 底线 | 说明 |
|---|---|
| **不交证件/人脸** | 一旦提交就收不回；绝大多数场景不需要 |
| **不给其他服务的密码** | 任何代理商都不需要你别的账号密码 |
| **不在私下渠道转账** | 只走官网支付（很多商家自己都写明"客服不接受私下付款"） |

---

## 五、一句话

> **把所有"形容词"翻译成"字段"，把所有的"承诺"落到"条款"。**
> **然后你会发现：能验的东西不多，但那几个字段足够做判断。**
