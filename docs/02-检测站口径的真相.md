# 02 · 检测站口径的真相（为什么 ping0 说"家庭宽带"、别的网站说"数据中心"）

**为什么同一个 IP，不同网站给出的结论完全相反？**

因为**它们量的不是同一个东西**。把它们当成"真假判官"是最大的误解来源。

---

## 一句话结论

> **这些网站的"标签"（家庭宽带 / 数据中心 / 原生 / 机房）全部是各自数据库的主观归类，口径不同、结论就会相反。**
> **它们只能用来"交叉参考"，不能用来"定论"；定论要靠 RIR 注册数据。**

---

## 逐个拆解（附官方说明原文）

### ping0.cc —— 它的"家庭宽带"是**兜底标签**

**官方 FAQ 原文**：

> **Q1**：「"IDC机房IP"：特指机房专用的 IP，**除此外的 IP 均标记为"家庭宽带IP"**。」
>
> **Q6**：「当一个 IP 显示为"家庭宽带"时，**仅能说明它不是"IDC 机房宽带"，但无法确定它是"家庭宽带"**，也可能是商业宽带或校园网。」
>
> **Q9**：「原生 = 注册国家与机房/实际地理位置国家一致；**大部分家庭宽带 IP 属于原生 IP，部分本地 IDC 服务商也会使用原生 IP**。」
>
> **Q18**：「适用场景判定…**建议以实际业务表现作为最终依据**。」

**怎么用**：
- ❌ **不要信**它的"家庭宽带 IP"标签（这是"非机房名单"的兜底，证明力极弱）
- ✅ **可以看**它的"**风控值**"（官方分级：≤15 极度纯净 / 15–25 纯净 / 25–40 中性 / 40–50 轻微 / >70 极差）
- ✅ **可以看**它的"**ASN 历史 / 企业历史**"（能看出这个段被哪些组织用过）

---

### 补充：「双 ISP」到底是什么？（ping0 官方 FAQ Q2 / Q4）

**「双 ISP」不是"这个 IP 由两家 ISP 提供服务"** —— 它是 ping0 **两个字段的标签组合**。

**官方原文**：

> **Q2**：「关于识别是 IDC 机房 IP 还是 家庭宽带 IP，可以根据 **`ASN 所有者` 和 `企业` 是否为 ISP** 来简单的判断。
> 这也是其它网站所使用的方法，然而**这只能说明这个 IP 的拥有者是 ISP，并不代表此 IP 实际使用在家庭宽带里**。」
>
> **Q4**：「**为什么双 ISP 还会显示"IDC机房IP"？**
> **双 ISP 只是说明这个 IP 的拥有者是 ISP，并不代表 IP 实际用在家庭宽带里。**
> 以 `ping baidu.com` 得到的 `110.242.68.66` 为例，属于联通 IP，
> **在其它网站上查会发现他是双 ISP，还会显示 家庭宽带IP，但很明显这是个 IDC机房IP。**」

**机制（我们实测对比后归纳）**：

| 段的类型 | 两栏的关系 | ping0 显示 |
|---|---|---|
| **骨干网自有段** | `ASN 所有者` 与 `企业` 是**同一家**（例如都是同一家 Tier-1） | **两栏都标 ISP →「双 ISP」** |
| **小运营商租用转接的段** | 两栏**不同**（广播方是 Tier-1，持有者是独立小 ISP） | **只有一栏标 ISP →「单 ISP」** |

**→ 所以「双 ISP」反映的是"两栏是同一家"（即骨干自有段），并不是"质量更高"。**

**⚠️ 两点诚实说明**：
1. 上面这个"机制"是我们**少量样本对比后归纳**的，**样本有限**；
2. ping0 **官方自己就说「双 ISP」不代表性**（见 Q4 原文）。

**→ 结论：不要用「双 ISP / 单 ISP」来判断好坏。** 可靠判据仍然是：
**RDAP 的 `registrant`**（段注册给谁）+ **Scamalytics 的 `Server`**（是不是商用服务器）。

---

### ip.cx —— 它看的是"**谁在广播**"

它的 `IP 类型` 字段**跟着广播 ASN 走**：

| 广播方 | 它的判定 |
|---|---|
| **Tier-1 骨干**（NTT / GTT / Cogent） | ❌ **数据中心** |
| 消费级运营商 | 通常是非数据中心 |

**所以**：一个"小 ISP 持有、但挂在 Tier-1 骨干下广播"的 IP，**会被它直接判成数据中心** —— 这不是"它错了"，而是**它量的是广播层**。

⚠️ 另外：**它查询需要人机验证**，无法批量预判。

---

### Scamalytics —— 只看 `Server` 字段，别看 Fraud Score

| 字段 | 含义 | 注意 |
|---|---|---|
| `Fraud Score` | 是否被用于欺诈/滥用 | ⚠️ **机房段也常见 0 分**（只说明"没被滥用"，不说明"是住宅"） |
| **`Server`** | **是不是商用服务器** | ✅ **这才是关键** |
| `Residential Proxy` | 是否属于住宅代理网络 | ✅ 参考 |
| `Datacenter` | 是否位于机房 | ✅ 参考 |
| `External Blacklists` | 5 家开源黑名单 | ✅ 全 No 才好 |

**隐藏线索**：页面文案里出现 **"commercial server"** → 直球判定为服务器。

---

### ip.huzhihui.com —— **只能测你自己**

它显示的是**当前访问者的 IP**（分"国内探测 / 外部探测"两栏），**不能指定查询别人的 IP**。

**所以**：它适合"验证自己手上的 IP"，**不适合"预判商家给的示例 IP"**。

---

### ipinfo.io —— 经常**返回空**

对小众号段，`org` 字段经常为空。**不能单独依赖**。

---

## 对照表（同一个 IP，五家结论不同的原因）

| 数据源 | 它实际在量什么 | 结论可能 |
|---|---|---|
| **RIR RDAP** | **号段注册持有者**（客观事实） | ✅ 唯一权威 |
| RIPEstat | 当前广播 ASN | 中性 |
| ip.cx | 广播方类型 | 偏"机房" |
| ping0 | 人工标注段名单 | 偏"家宽"（兜底） |
| Scamalytics | 欺诈分 + 服务器特征 | 中肯 |
| ipinfo | 商业数据库 | 可能空 |

---

## 使用规则（三条）

1. **不可跨站比较绝对值** —— 不同站的"纯净度/风险值/类型"不是同一把尺子；
2. **只能同站纵向比较** —— 用**同一个站**测你的多个候选 IP，看相对排序；
3. **定论看 RDAP** —— 标签类指标只做交叉参考。

## 一句话记住

> **检测站是"意见"，RIR 是"事实"。**
> **意见可以打架，事实不会。**

## 实测发现的"滑块陷阱"（Scamalytics）

> Scamalytics 页面上那个**可调滑块，只影响 Fraud Score**。
> 而**机房段同样可以得 0 分** —— 实测实例：某经纪人段 `Fraud Score = 0`，但 `Server = Yes`。

**结论**：**把滑块拖到最严（0），也筛不掉机房段。**

真正决定判断的是这两个字段：

| 该看的 | 不该只看的 |
|---|---|
| **`Proxies → Server`**（Yes = 商用服务器） | ~~Fraud Score 滑块~~ |
| **`Residential Proxy`**（是否住宅代理网络） | ~~页面顶部的风险条颜色~~ |
| 外加 **RDAP 的 netname**（号段持有者） | |

**一句话**：**Fraud Score 低 ≠ 是住宅**；`Server = No` **才**是你要的那个信号。

## 补充 B · 一个必须知道的利益关系：检测站的"广告位"就是代理商

我们在实测时，抓取了 ping0 页面上**那些"关闭广告"按钮的真实跳转目标**。
结果是：**它们全部指向代理服务商，而且链接里带推广参数**（`invite_code=` / `ref=` / `utm_source=` / `kwd=` 等）。

| 跳转目标（域名） | 链接携带的推广参数形态 |
|---|---|
| `onesproxy.com` | `?user_source=1&invite_code=…` ← **返佣邀请码** |
| `linkstatic.com` | `?kwd=…-ping0` |
| `proxy-cheap.com` | `?utm_source=ping0cc&utm_medium=banner` |
| `1024proxy.com` | `?kwd=…-ping0` |
| `swiftproxy.net` | `?ref=ping0` |
| `rapidproxy.io` | `?ref=ping0` |
| `accszone.com` | `?utm_source=ping0&utm_medium=banner` |
| `proxy001.com` | `?ppf=…_ping0` |

**这说明什么**：

1. **这个检测站的收入来自"给代理商导流"**（带 `invite_code` 的就是**返佣**）；
2. **它的检测结论与广告主的利益方向一致** ——
   例如把"骨干机房段"标成"家庭宽带 IP"，**恰好有利于卖这些段的商家**；
3. **这不是说它的数据是编的**，而是说：**它是"有商业关系的意见"，不是"中立的事实"。**

**你可以自己核对**：打开 ping0 的任意 IP 详情页 → 看那些"关闭广告"按钮指向哪。

> ⚠️ **本文不把这些写成可点击的外链** —— 一是它们都带推广参数，二是本仓库承诺"零外链"。

**这也是本仓库"关于中立性"那一节能成立的原因**：
**我们既不挂链接，也不接受任何一方的赞助，所以没有"必须偏袒某家"的理由。**
