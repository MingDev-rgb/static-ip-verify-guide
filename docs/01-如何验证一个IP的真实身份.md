# 01 · 如何验证一个 IP 的真实身份（静态住宅 IP / 原生 IP 到底是不是机房段）

**核心思路：不要看商家给的标签，去看 RIR 的注册记录。**

商家会告诉你这个 IP 是"原生住宅""双 ISP""独享"；但有一件事他们**改不了**：
**这个号段在 RIR（区域互联网注册管理机构）的注册记录里，写着谁的名字。**

---

## 三层验证法（按权威度排序）

### 第 1 层：RDAP —— 这个号段是**谁的**？（最权威）

**RDAP** 是 RIR 官方提供的注册数据查询（WHOIS 的现代替代），返回的是**法律意义上的持有者**。

```bash
# RIPE（欧洲）
curl -s "https://rdap.db.ripe.net/ip/1.2.3.4" | jq '{handle, name, country, type, startAddress, endAddress}'

# ARIN（北美）
curl -s -H "Accept: application/rdap+json" "https://rdap.arin.net/registry/ip/1.2.3.4" | jq '{name, handle, startAddress, endAddress}'

# APNIC（亚太）
curl -s "https://rdap.apnic.net/ip/1.2.3.4"
```

**重点看 `name`（netname）和 `country`**：

| 看到什么 | 含义 |
|---|---|
| `name` 是**电信运营商**（如 `DE-TELEKOM-...`） | ✅ 大概率是真运营商段 |
| `name` 是**主机商 / 云服务商 / 网络技术公司** | ⚠️ 机房或批发商的段 |
| `country` 与 IP 声称的位置**不一致** | ⚠️ 跨国转手的号段（批发商特征） |
| `type` = `LEGACY` + 大量同前缀段 | ⚠️ 老号段，常被反复倒手 |

---

### 第 2 层：RIPEstat —— 现在**谁在广播它**？

**持有者**和**广播者**经常是两方：号段属于 A，但通过 B（Tier-1 骨干）对外广播。

```bash
curl -s "https://stat.ripe.net/data/prefix-overview/data.json?resource=1.2.3.4" \
  | jq '.data | {resource, asns: [.asns[] | {asn, holder}]}'
```

**为什么这层重要**：

| 现象 | 说明 |
|---|---|
| 广播 ASN = **NTT / GTT / Cogent** 这类 Tier-1 | ⚠️ 这是**骨干网络**，天然是"机房"属性。商家可能把"NTT"包装成卖点（"双 NTT 线路"），但**Tier-1 是最像机房的一类** |
| 广播 ASN = **消费级运营商**（Comcast / AT&T / Deutsche Telekom） | ✅ 更接近"真住宅" |
| 广播 ASN ≠ 注册持有者 | ⚠️ **典型的"经纪人号段"**（见文档 03） |

---

### 第 3 层：Scamalytics —— 第三方风控库**怎么看它**？

**注意：不要只看 Fraud Score！** 那是"是否被用于欺诈"，**机房段也可以是 0 分**。

```bash
# 用浏览器打开（有反爬，命令行会被拦）
https://scamalytics.com/ip/1.2.3.4
```

**要看的是这四个字段**：

| 字段 | 通过 | 不通过 |
|---|---|---|
| **Proxies → Server** | `No` | **`Yes` = 商用服务器** |
| **Residential Proxy** | `No`（或视情况） | — |
| **Datacenter** | `No` / `Unknown` | `Yes` |
| **External Blacklists**（Firehol / IP2ProxyLite / IPsum / Spamhaus / X4Bnet） | 全部 `No` | 任一 `Yes` |

**还有一个隐藏线索——它的结论文案**：

> 如果页面出现 **"not a standard domestic connection, it is a commercial server"** → 这是**直球判定**：它不是家宽，是一台商用服务器。

---

### 第 4 层（可选）：ipinfo

```bash
curl -s "https://ipinfo.io/1.2.3.4/json"
```

⚠️ **注意**：ipinfo 对**小众号段经常返回空**（`org` 为空）→ **不能只靠它**。

## 判定表（四个数据源一起看）

| RDAP name | 广播 ASN | Scamalytics Server | 综合判定 |
|---|---|---|---|
| 运营商 | 运营商 | No | ✅ **像真住宅/ISP** |
| 主机商 / 网络技术公司 | Tier-1 骨干 | Yes | ❌ **机房段贴牌** |
| 主机商 | Tier-1 骨干 | No | ⚠️ **灰色**（干净但仍非住宅） |
| 小 ISP / 地区网络商 | Tier-1 | No | ⚠️ **比机房好，比运营商差** |

---

## 实战：三步看穿"原生住宅"话术

```
第 1 步：拿到商家展示的示例 IP（或买最小额拿一个真 IP）
第 2 步：RDAP 查 netname → 是运营商还是主机商？（30 秒）
第 3 步：Scamalytics 查 Server 字段 → Yes 还是 No？（1 分钟）
```

**如果商家连"示例 IP"都不敢展示** → 这本身就是一个信号（真货不怕验）。

---

## 一句话记住

> **"原生"是形容词（注册国=位置国，跟是不是住宅无关）；**
> **`netname` 和 `Server` 字段是名词。**
> **信名词，别信形容词。**
