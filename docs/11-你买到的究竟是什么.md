# 11 · 你买到的究竟是什么：七层资源等级与供应链

> **一句话**：代理 IP 不是“商品”，是“转售凭证”。
> 你付的钱，买的不是那个 IP，是它离运营商的距离。

这篇不推荐商家，也不排名；只把“你买到的层级”拆开。

---

## 一、先换一个问题

大多数人问：

> “哪家住宅 IP 靠谱？”

正确的问题应该是：

> “我买的这个东西，在供应链的哪一层？”

因为“住宅 IP”不是一种商品，是一组形容词。
商家可以把同一批机房段，包装成“原生 / 双 ISP / 住宅 / 独享”；
但 RDAP 里的注册人、BGP 里的广播方、风控库里的字段，不会跟着话术变。

---

## 二、供应链地图

```text
真实用户 / 运营商线路
        │
        ▼
┌───────────────────┐
│ 1. 真住宅          │  绑地址、CPE、人名；1:1，不能批发
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 2. 小众段 ISP 零售 │  小 ISP 直营/零售静态段；极少
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 3. 大众段 ISP 零售 │  NTT/Comcast/HiNet 商宽/专线；不对境外散户
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 4. ISP 代理        │  租 ISP 段，机房/POP 托管；能买，但抽卡
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 5. 机房伪装 ISP    │  名字像 ISP，实际 hosting/代理网络
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 6. IDC 机房 IP     │  明确 hosting/IDC ASN
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 7. 广播数据中心    │  Tier-1 广播下的客户段；ASN 像 ISP，实际 DC
└───────────────────┘
```

**越往下，离真实用户越远，价值越低，越容易在卡池里买到。**

## 三、七层等级

### 1. 真住宅

**定义**：运营商消费级线路，IP 绑在具体地址、具体 CPE、具体人名下。

**典型**：自己家宽、海外朋友家宽、手机国际漫游。

**能不能在卡池里买到**：几乎不能。

**为什么**：

- 能 1:1 卖，不能切成随机凭证批发；
- 一旦规模化，它就已经进入代理链条，不再是“真住宅”；
- 运营商不会为一个小海外买家拆段。

**判断**：不是查 IP，是查合同/安装地址/线路。代理市场里买不到。

---

### 2. 小众段 ISP 零售

**定义**：小型 ISP 的直营/零售静态段，通常是 direct allocation 或 ISP 分配。

**典型**：I-2000（已枯竭的例外）。

**能不能在卡池里买到**：极少，靠本地关系/运气。

**判断**：

- RDAP registrant 是 ISP，不是主机商/经纪人；
- `Server = No`、Fraud 低、ping0 不标 IDC；
- 库存极小，会枯竭，不可指定。

**注意**：小 ISP 不等于“小机房”；要看线路在谁手里。

---

### 3. 大众段 ISP 零售

**定义**：NTT/Comcast/HiNet 等大型运营商的商宽/专线静态 IP。

**典型**：本地商宽、企业专线。

**能不能在卡池里买到**：不对境外散户零售。

**判断**：

- 需要当地身份/地址/合同/安装；
- 不是“买个 IP”，是“拉条线”；
- 价格是安装费 + 月费，不是 $3/IP。

---

### 4. ISP 代理

**定义**：供应商从 ISP 租段，服务器托管在机房/POP；ASN 可能真是 ISP。

**典型**：Astound/CenturyLink 的“ISP 代理”。

**能不能在卡池里买到**：有，但抽卡。

**判断**：

- ASN 可能是真 ISP；
- 但 IP 物理在机房，`Server` 常为 Yes；
- RDAP 可能是 ISP 的客户块，不是零售线路；
- 速度/身份比纯 IDC 好，但仍不是住宅。

**一句话**：注册真，线路假。

---

### 5. 机房伪装 ISP

**定义**：拿 ISP/小运营商名字包装，实际是 hosting/代理网络。

**典型**：Lumina/Lietparkas、部分 Arisk 段。

**能不能在卡池里买到**：大量。

**判断**：

- RDAP 注册国/持有人与 ASN/位置不一致；
- ping0 常标 IDC；
- 一家检测站说“Residential”，另一家说“IDC”；
- 看 RDAP，不要看“Residential”标签。

**一句话**：名字像 ISP，线路在机房。

---

### 6. IDC 机房 IP

**定义**：明确的 hosting/IDC ASN。

**典型**：Arisk/DIL/Bunny。

**能不能在卡池里买到**：大量。

**判断**：

- ASN/公司类型是 hosting；
- `Server = Yes` 常见；
- 黑名单可能整段；
- 适合“只要能连”，不适合“养号”。

---

### 7. 广播数据中心

**定义**：Tier-1 骨干广播下的客户段；ASN 看起来是 ISP，实际持有者是客户/数据中心。

**典型**：Westeros/NTT、Wisdom/IIJ。

**能不能在卡池里买到**：大量。

**判断**：

- ASN 是 NTT/IIJ，但 RDAP 注册名是客户公司；
- 广播方 ≠ 持有者；
- `Server = Yes`、黑名单风险；
- 最容易骗过“只看 ASN”的人。

**一句话**：门牌是 NTT，房产证是别人。

## 四、价值论

> **离真实用户越近，价值越高；经过的中间商越多，价值越低。**

| 路径 | 离真实用户 | 价值 | 能不能规模化卖 |
|---|---|---|---|
| 运营商专线 / 本地商宽 | 最近 | 最高 | 要当地身份/地址/安装 |
| 海外朋友家宽（经同意） | 很近 | 很高 | 1:1，人情，不能批发 |
| 国际漫游数据 | 近 | 高 | 应急，会变/共享 |
| ISP 零售 | 中 | 中高 | 要合同/安装，起订量高 |
| ISP 代理 | 远 | 中 | 能卖，但服务器在机房 |
| 机房伪装 ISP | 更远 | 低 | 大量 |
| IDC / 广播数据中心 | 最远 | 最低 | 大量 |

**所以：**

- 你多花的钱，如果买的是“概率”，不是“线路”；
- 你换商家，不如换等级；
- 你换等级，不如换路径。

---

## 五、为什么没有“定制真住宅”商家

从商业上不成立：

1. 运营商自己就能开线、分配静态 IP，不需要中间商；
2. 真住宅要绑地址、CPE、人名，不能切成随机凭证批发；
3. 运营商不会为一个小海外买家拆段；
4. 所以“定制真住宅”要么是本地线路转售，要么是机房伪装；
5. 能规模化卖的“住宅”，一定已经进入代理链条，不再是真住宅。

**这不是商家良心问题，是供应链结构问题。**

---

## 六、为什么市场没有明确的分层定价

| 原因 | 结果 |
|---|---|
| 买家无法验证 ASN/注册人/线路位置 | 卖家可以用“原生/双 ISP/住宅”统一包装 |
| 同一个池子可以换多个门面 | 同货不同价，价格看品牌不看等级 |
| 抽卡隐藏了方差 | 你买到的是概率，不是确定等级 |
| 退款/换货成本高 | 卖家没有动力披露真实层级 |
| 推荐带返佣 | “测评”本身有立场 |

所以：

> **把某一家说成“稳”，本质上是在推荐一个卡池。**

---

## 七、抽卡论

- 下游、中游、上游，底层都是“池子里随机分配”；
- 上游只是抽卡次数更多、单价更低，不是“真货层”；
- 同一批经纪人段，可以同时供给多家下游；
- 日本便宜池：`103.*.148` / `43.*.197` 是 Arisk，`103.*.120` 是 NTT/M-Square，整段黑名单；
- 不是日本 ISP 全黑，是这条便宜供应链全黑。

证据、概率表、脱敏池反查，见 [文档 09](09-实测数据集.md)。

## 八、养号结论

| 需求 | 最低档 | 说明 |
|---|---|---|
| 注册 / 养号 / 长期运营 | **ISP 零售** | 够用；但还要账号、手机号、浏览器、支付、行为一致 |
| 勉强能用 | **ISP 代理** | 有风险，抽卡，不保证 |
| 机房伪装 / IDC / 广播 | **不建议** | 掩耳盗铃，不如继续用梯子 |
| 只要看内容 / 搜索 | 干净梯子即可 | 不必买“住宅”标签 |

**IP 不能单独把账号“养白”；它只能不拖后腿。**

账号层（手机号/浏览器/支付/行为）是另一个问题，本文不展开，也不提供绕过实名的做法。

## 九、判断标准

拿到一个 IP，按这个顺序：

1. **RDAP**：号段注册在谁名下？
2. **RIPEstat**：当前由哪个 ASN 广播？
3. **Scamalytics**：`Server` / `Anonymizing VPN` / Fraud；
4. **黑名单**：Spamhaus SBL / AbuseIPDB；整段黑名单，换尾数没用；
5. **ping0 / 其他站**：交叉参考，别当唯一判据。

**身份是门票，记录是座位。**

- 身份干净 + 记录脏 → 还有救；
- 身份脏 + 记录干净 → 对查 ASN 的平台，仍然出局；
- 分数干净 ≠ 身份干净。

命令见 [文档 01](01-如何验证一个IP的真实身份.md)。

---

## 十、一句话总结

> **你买的不是“住宅 IP”，是供应链上的一张转售凭证。**
> 离运营商越近，越值钱；经过的中间商越多，越不值钱。
> 推荐商家没有意义——你真正要选的是等级和路径。
